# Cowork session on the Mac — start here

This folder is the kickoff kit for the one session that has to run on Dan's
Mac: the machine with the Intuit credentials, the keychain, and a browser that
can reach `developer.intuit.com`. Everything that could be built without those
has been built on the branch already.

| File | What |
|---|---|
| `PREREQS.md` | The checklist to complete before opening the session. Five items. |
| `KICKOFF.md` | The prompt to paste into the new session. Self-contained. |
| `ACCEPTANCE.md` | What "done" looks like, copied from `HANDOFF.md` §5 and extended. |

## How to start

1. On the Mac: `git clone https://github.com/dancynamon/QuickBooksKILLA.git` and
   `git checkout claude/modest-allen-82wp1w`. Never put the clone or the
   replica database in Dropbox (`README.md`, "Two things not to do later").
2. Work through `PREREQS.md`.
3. Open Cowork from the desktop app (not a browser session: the keychain and
   the loopback redirect need the device bridge), mount the clone, paste
   `KICKOFF.md`.
